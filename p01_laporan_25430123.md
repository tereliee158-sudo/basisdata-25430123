### 2. Tujuan Praktikum

Praktikum ini bertujuan untuk mengenali lingkungan basis data MariaDB, memeriksa versi server dan mode SQL, memahami database yang tersedia, serta mempelajari pembagian hak akses berdasarkan akun pengguna. Praktikum juga bertujuan memastikan bahwa akun latihan, akun proyek, dan akun tamu memiliki hak akses sesuai dengan kebutuhannya.

### 3. Hasil Pemeriksaan Lingkungan

#### 3.1 Versi Server dan Akun Aktif

Perintah yang digunakan:

```sql
SELECT VERSION(), CURRENT_USER();
```

Hasil pengujian menunjukkan bahwa server menggunakan MariaDB versi `10.4.32-MariaDB` dan akun yang aktif adalah `root@localhost`. Hal ini membuktikan bahwa koneksi ke server basis data berhasil dilakukan.

#### 3.2 Mode SQL

Perintah yang digunakan:

```sql
SELECT @@sql_mode;
```

Mode SQL yang diperoleh adalah:

`NO_ZERO_IN_DATE, NO_ZERO_DATE, NO_ENGINE_SUBSTITUTION`

Hasil tersebut menunjukkan pengaturan mode SQL yang sedang aktif pada server MariaDB.

#### 3.3 Daftar Database

Perintah yang digunakan:

```sql
SHOW DATABASES;
```

Hasil pemeriksaan menampilkan tujuh database, yaitu `information_schema`, `kopma_123`, `mysql`, `performance_schema`, `perpus_123`, `phpmyadmin`, dan `test`.

Database `kopma_123` digunakan untuk latihan, sedangkan `perpus_123` merupakan database proyek dengan tema Perpustakaan.

#### 3.4 Hak Akses Akun Latihan

Perintah yang digunakan:

```sql
SHOW GRANTS FOR 'mhs_123'@'localhost';
```

Hasil pemeriksaan menunjukkan bahwa akun `mhs_123` memiliki hak akses penuh pada database `kopma_123`, tetapi tidak diberikan hak akses global khusus pada seluruh server.

#### 3.5 Hak Akses Akun Proyek

Perintah yang digunakan:

```sql
SHOW GRANTS FOR 'dev_123'@'localhost';
```

Hasil pemeriksaan menunjukkan bahwa akun `dev_123` memiliki hak akses penuh pada database `perpus_123`. Hak akses tersebut tidak mencakup database latihan `kopma_123`.

#### 3.6 Hak Akses Akun Tamu

Perintah yang digunakan:

```sql
SHOW GRANTS FOR 'tamu_123'@'localhost';
```

Hasil pemeriksaan menunjukkan bahwa akun `tamu_123` hanya memiliki hak untuk membaca data (`SELECT`) pada database `kopma_123`. Akun ini tidak diberikan hak akses untuk mengubah atau membuat tabel pada database tersebut.
